# Node.js Express API with TypeScript and Bearer Token Authentication

This repository contains a simple Node.js REST API built with Express.js and TypeScript. It demonstrates basic project structure, configuration loading from a YAML file, and Bearer token authentication using Passport.js.

## Features

*   **Express.js:** Web framework for Node.js.
*   **TypeScript:** Superset of JavaScript adding static types.
*   **YAML Configuration:** Application settings managed via `config.yaml`.
*   **Passport.js:** Authentication middleware for Node.js.
*   **Bearer Token Authentication:** Protects specific API endpoints using `passport-http-bearer`.
*   **Development & Production Scripts:** Includes scripts for easy development workflow (`npm run dev`) and production deployment (`npm run build`, `npm run start`).

## Setup

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    cd <repository-directory>
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
    This command installs all the necessary dependencies listed in `package.json`.

## Configuration

Application configuration is managed in the `config.yaml` file located in the project root.

```yaml
port: 3000
bindAddress: 0.0.0.0
bearerToken: some-secret-token
```

*   `port`: The port number the server will listen on.
*   `bindAddress`: The network address the server will bind to (e.g., `0.0.0.0` to listen on all available network interfaces, `127.0.0.1` for localhost only).
*   `bearerToken`: The secret token required to access protected API endpoints. **Change this to a strong, unique secret in a real application.**

## Running the Server

### Development Mode

For development, use the `dev` script. This uses `nodemon` to automatically restart the server when file changes are detected and `ts-node` to run TypeScript directly.

```bash
npm run dev
```
The server will start, typically listening on `http://0.0.0.0:3000` (or as configured in `config.yaml`).

### Production Mode

For production, you need to build the TypeScript code into JavaScript first, then run the compiled code.

1.  **Build the application:**
    ```bash
    npm run build
    ```
    This command uses `tsc` (the TypeScript compiler) to compile the code from `src/` into the `dist/` directory, according to the settings in `tsconfig.json`.

2.  **Start the server:**
    ```bash
    npm run start
    ```
    This command runs the compiled application entry point (`dist/server.js`) using Node.js.

## API Endpoints

The API routes are prefixed with `/api`.

### Public Endpoint

*   **URL:** `/api/public`
*   **Method:** `GET`
*   **Authentication:** None required.
*   **Description:** Returns a simple public message.

**Example using `curl`:**
```bash
curl http://localhost:3000/api/public
```
*(Replace `localhost:3000` with the actual host and port if different)*

**Expected Response:**
```json
{
  "message": "This is a public route. Anyone can access it."
}
```

### Secure Endpoint

*   **URL:** `/api/secure`
*   **Method:** `GET`
*   **Authentication:** Bearer Token required.
*   **Description:** Returns a protected message and user information after successful authentication.

**Example using `curl`:**

You need to provide the `bearerToken` from `config.yaml` in the `Authorization` header.

```bash
# Replace 'some-secret-token' with the actual token from config.yaml
TOKEN="some-secret-token"

curl -H "Authorization: Bearer ${TOKEN}" http://localhost:3000/api/secure
```
*(Replace `localhost:3000` with the actual host and port if different)*

**Expected Response (Success):**
```json
{
  "message": "This is a protected route. Authentication successful!",
  "user": {
    "scope": "all",
    "username": "service-account"
  }
}
```

**Expected Response (Failure - Incorrect or Missing Token):**
```
Unauthorized
```
(Status code: 401 Unauthorized)
